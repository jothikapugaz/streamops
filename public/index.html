What is observability?

In production, services emit metrics, logs, and traces. This screen uses sample values to help you learn the concepts; it is not monitoring a real system.

How to read these signals

A quick field guide for a junior engineer

MMetrics

Numerical measurements over time, such as request latency or error rate.

LLogs

Timestamped records that describe what happened inside an application.

TTraces

A request's journey through multiple services, helping locate a slow dependency.
